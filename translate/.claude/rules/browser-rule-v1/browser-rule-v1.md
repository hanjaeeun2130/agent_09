# 브라우저 제어 규칙 (v1)

이 규칙은 이 프로젝트에서 웹 브라우저를 열거나 제어할 수 있는 작업이 있을 때마다 적용됩니다.

## 1. 기본 도구

- 모든 웹 브라우저 제어에는 **Playwright MCP**(`mcp__playwright__*`)를 사용합니다.
- 도구가 지연 로드(deferred) 상태라면, 사용하기 전에 필요한 도구를 ToolSearch 한 번으로 불러옵니다.
- Claude in Chrome 확장(`mcp__claude-in-chrome__*`)은 사용자가 명시적으로 요청한 경우에만 사용합니다(예: "크롬 확장으로", "Claude in Chrome").

## 2. 자동 호출 (트리거 키워드)

- 사용자의 메시지에 아래 키워드나 같은 뜻의 표현이 있으면, 따로 묻지 않고 바로 Playwright MCP를 호출합니다.
  - "브라우저를 열어서 작업" / "브라우저 열어서" / "브라우저 열어줘"
  - "웹 제어" / "웹 브라우저 제어"
  - "직접 작업" / "직접 들어가서" / "사이트에 들어가서 해줘"
- 작업 전체에는 CLAUDE.md의 작업 방식(todo list 먼저 보고, 승인 후 실행)이 그대로 적용됩니다. 계획이 승인되면 브라우저 사용 동의를 따로 묻지 않고 Playwright를 사용합니다.

## 3. 호출 전 동의 (키워드 없음)

- 사용자가 트리거 키워드를 쓰지 않았지만 Playwright MCP로 할 수 있는 작업이라면(예: 실제 웹페이지 확인, 화면 캡처, 폼 입력, 사이트 자료 수집), 먼저 사용자에게 묻습니다.
  - 예시: "이 작업은 브라우저를 직접 열어서(Playwright) 진행할 수 있습니다. 브라우저를 열어 작업해도 될까요?"
- 사용자가 동의한 뒤에만 Playwright MCP를 호출합니다. 사용자가 거절하면 다른 방법(예: WebSearch, WebFetch)을 쓰거나, 할 수 없는 부분을 설명합니다.

## 4. 안전 수칙

- 되돌리기 어려운 동작(로그인, 결제, 글 게시·발행, 메시지 전송, 데이터 삭제) 직전에는 브라우저 사용이 이미 승인되었더라도 멈추고 사용자에게 다시 확인합니다.
- 비밀번호나 결제 정보는 대신 입력하지 않고, 사용자에게 직접 입력하도록 요청합니다.
- 작업이 끝나면 브라우저를 닫습니다(`browser_close`).
- 브라우저에서 한 일을 보고하며, 실패하거나 건너뛴 단계도 함께 알립니다.
