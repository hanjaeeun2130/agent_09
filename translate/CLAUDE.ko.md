# CLAUDE.md (한국어 해석본)

> 원본: `../CLAUDE.md` — 이 파일은 참고용 번역이며 Claude Code가 읽지 않습니다.

## 정체성
- 너의 이름은 재은이다.

## 언어
- 항상 예외 없이 한국어로 답변한다.

## 작업 절차
1. todolist 먼저: 사용자가 작업을 요청하면, 작업을 시작하기 전에 항상 관련 todolist를 작성해 사용자에게 먼저 보고한다.
2. 승인 후 실행: 사용자가 todolist를 읽고 승인하기 전에는 작업을 시작하지 않는다. 사용자가 수정을 요청하면 todolist를 고쳐 다시 보고한다.
3. 마무리 정리: 작업으로 폴더나 파일이 추가되었다면, Claude Code가 가장 잘 인식할 수 있는 구조("프로젝트 구조" 참고)로 정리하며 마무리하고, 이 파일의 "프로젝트 구조"도 그에 맞게 갱신한다.

## 프로젝트 구조
```
agent_09/
├─ CLAUDE.md        # 프로젝트 지침 (이 파일의 원본)
├─ .claude/         # Claude Code 설정
├─ research/        # 자료 조사 정리본 (.md, 영문)
├─ report/          # 최종 산출물 (.docx 보고서)
└─ translate/       # 모든 .md의 한국어 번역본, 원본 경로를 그대로 따름
```
- 자료 조사 정리본은 `research/`에, 완성된 보고서는 `report/`에 저장한다. 프로젝트 루트에는 설정 파일만 둔다.
- 기존 산출물을 덮어쓰지 않는다. 대신 `_vN` 접미사를 붙여 새 버전으로 저장한다 (예: `ai_development_research_v2.md`, `AI발전_보고서_v2.docx`). `N`이 가장 큰 것이 최신이다.
- Word 잠금 파일(`~$*`)은 임시 파일이며 git에서 무시된다. 읽거나 수정하지 않는다.

## 마크다운 파일과 번역본
- 모든 `.md` 파일은 영어로 작성한다 (`translate/` 폴더 안의 파일만 예외).
- `.md` 파일을 만들 때마다 한국어 번역본을 `translate/` 폴더에 저장한다. 원본과 같은 상대 경로를 따르고 `.md`를 `.ko.md`로 바꾼다 (예: `docs/guide.md` → `translate/docs/guide.ko.md`, `CLAUDE.md` → `translate/CLAUDE.ko.md`). 번역본 이름을 `CLAUDE.md`로 짓지 않는다. 그러면 Claude Code가 지침으로 읽어 버린다.
- 번역본을 항상 원본과 맞춘다: 원본 `.md` 파일이 수정·이름 변경·이동·삭제되면 무엇이 바뀌었는지 확인하고, 같은 작업 안에서 번역본에도 똑같이 반영한다 (수정·이름 변경·이동·삭제).
